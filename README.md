# FitnessOS

FitnessOS is a governed, vendor-neutral athlete performance platform.

This repository contains implementation artifacts only. Architecture, governance, canonical semantics, source authority, QA certification, and release promotion remain owned by their designated FitnessOS authorities.

## Engineering controls

- Implement approved architecture only.
- Preserve canonical history and lineage.
- Keep provider schemas isolated from canonical contracts.
- Do not encode source authority outside governed CMAM inputs.
- Engineering produces QA candidates; Engineering does not self-certify or promote production releases.

## Current implementation state

Foundation implementation initiated under FOS-HND-ENG-001 and EP-FOS-001 through EP-FOS-015.
